ArgEditor - an editor for F1GP

In early 1992, Geoff Crammond and Microprose released Formula One Grand Prix. The rest, as they say, is history.

Quite soon, a number of tools and editors appeared for the game. These were excellent pieces of software, but time has moved on, and most of them unfortunately do not work on modern versions of Windows.

ArgEditor is a fresh take on an F1GP editor which works on all recent versions of Windows.

Features

  • Update the names of teams and drivers
  • Set computer car horsepower levels and driver performance levels
  • Paint cars, pit crew clothing and helmets
  • Full undo/redo functionality when editing
  • Update the points system
  • Create and edit car setup files
  • and more!

To begin your editing adventure download ArgEditor now and go to the introduction page to get started!

Are you interested in editing F1GP tracks? Check out ArgTrack!

System requirements

  • Windows XP, Vista SP1, 7, 8, 8.1 or 10
  • Microsoft .NET Framework 4.0
  • F1GP (European) or World Circuit (US) version 1.05, including decompressed files
