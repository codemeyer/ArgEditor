# Keyboard Shortcuts

<p>
    There are various keyboard shortcuts available based on which part of the
    user interface you are currently viewing.
</p>

<h2 id="all-screens">All screens</h2>

<table class="table table-bordered table-striped table--small">
    <thead>
        <tr>
            <th>Shortcut</th>
            <th>Command</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>F1</td>
            <td>Opens web browser to show help/documentation</td>
        </tr>
    </tbody>
</table>


<h2 id="car-set-tab">Car Set tab</h2>

<h3 id="all-tabs">All tabs</h3>

<table class="table table-bordered table-striped table--small">
    <thead>
        <tr>
            <th>Shortcut</th>
            <th>Command</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Ctrl + O</td>
            <td>Load a car set</td>
        </tr>
        <tr>
            <td>Ctrl + S</td>
            <td>Save ArgEditor (.arged) car set</td>
        </tr>
        <tr>

        </tr>
    </tbody>
</table>
