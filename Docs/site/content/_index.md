ArgEditor is an editor for the old PC racing game
[Microprose Formula One Grand Prix](https://en.wikipedia.org/wiki/Formula_One_Grand_Prix_(video_game)),
first released in 1992.

After the game's initial release, a large number of tools and editors appeared.
These were excellent pieces of software, but time has moved on, and most of them
unfortunately do not work on modern versions of Windows.

ArgEditor is a fresh take on an F1GP editor, and it works on all recent versions of Windows!

<img src="/argeditor/images/cars.png" alt="Screenshot of ArgEditor" class="img-fluid" />


## Features

- Update the names of teams and drivers
- Set computer car horsepower levels and driver performance levels
- Paint cars, pit crew clothing and helmets
- Full undo/redo functionality when editing
- Update the points system
- Update the driver selection menu images
- Create and edit car setup files
- and more!

Are you interested in editing F1GP tracks? Check out <a href="/argtrack">ArgTrack</a>!
