# System Requirements

Below are the system requirements for the current version of ArgEditor.


## Supported F1GP/WC versions

ArgEditor will be able to edit data for the following versions of Formula One Grand Prix
and World Circuit:

- F1GP (European) 1.05
- World Circuit (US) 1.05

All other versions are currently unsupported. If you attempt to export data to an
unsupported version of F1GP, you will be unable to do so, and informed why.


## Supported Windows versions

ArgEditor will run on any of the following versions of Windows:

- Windows XP
- Windows Vista SP1 (or later)
- Windows 7
- Windows 8
- Windows 8.1
- Windows 10


## Microsoft .NET Framework

ArgEditor requires that the Microsoft .NET Framework 4.0 is installed.

If you are running Windows XP, Windows Vista or Windows 7, your installation of Windows may not
feature the Microsoft .NET Framework 4.0 that is required by ArgEditor. In this case, starting the
program will display an error saying "The application failed to initialize properly." If this happens,
you should try to download and install the Microsoft .NET Framework 4.0 Client Profile, which can
be found here:
<a href="https://www.microsoft.com/en-us/download/details.aspx?id=24872">https://www.microsoft.com/en-us/download/details.aspx?id=24872</a>
