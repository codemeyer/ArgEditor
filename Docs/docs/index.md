# ArgEditor - an editor for F1GP

In early 1992, Geoff Crammond and Microprose released Formula One Grand Prix.
The rest, as they say, is history.

Quite soon, a number of tools and editors appeared for the game. These were
excellent pieces of software, but time has moved on, and most of them
unfortunately do not work on modern versions of Windows.

ArgEditor is a fresh take on an F1GP editor.

![ArgEditor screenshot](img/cars.png)

Note: This software is still in beta, and many more features will be
added in due time.

It is better to be safe than sorry! Please make a backup of your F1GP folder
before using this software.


## Features

* Update the names of teams and drivers
* Set computer car horsepower levels and driver grip levels
* Paint cars, pit crew clothing and helmets


## System requirements

* Windows Vista SP2, 7 SP1, 8, 8.1 or 10
* Microsoft .NET Framework 4.5.2 ([download](https://www.microsoft.com/en-us/download/details.aspx?id=42643))
* F1GP (European) or World Circuit (US) version 1.05
