# Keyboard Shortcuts

There are various keyboard shortcuts available based on which part of the
user interface you are currently viewing.


## All screens

| Shortcut        | Command                                        |
|-----------------|------------------------------------------------|
| F1              | Opens web browser to show help/documentation   |



## Car Set tab

### All tabs

| Shortcut        | Command                                        |
|-----------------|------------------------------------------------|
| Ctrl + O        | Load a car set                                 |
| Ctrl + S        | Save ArgEditor (.arged) car set                |
| Ctrl + Alt + S  | Save F1Ed (.1ed) car set                       |


### Performance tab

| Shortcut        | Command                                        |
|-----------------|------------------------------------------------|
| +               | Increase performance value in focus by 1       |
| Shift + +       | Increase performance value in focus by 10      |
| -               | Decrease performance value in focus by 1       |
| Shift + -       | Decrease performance value in focus by 10      |



### Cars tab

| Shortcut        | Command                                             |
|-----------------|-----------------------------------------------------|
| Ctrl + Z        | Undo last painting action on current car/pit crew   |
| Ctrl + Y        | Redo painting action on current car/pit crew        |
| Ctrl + C        | Copy current car to clipboard                       |
| Ctrl + P        | Paste car from clipboard to current car             |
| +               | Select next brighter color in palette               |
| -               | Select next darker color in palette                 |



### Helmets tab

| Shortcut        | Command                                             |
|-----------------|-----------------------------------------------------|
| Ctrl + Z        | Undo last painting action on current helmet         |
| Ctrl + Y        | Redo painting action on current helmet              |
| Ctrl + C        | Copy current helmet to clipboard                    |
| Ctrl + P        | Paste helmet from clipboard to current helmet       |
| +               | Select next brighter color in palette               |
| -               | Select next darker color in palette                 |
