# Menus


## Open and Save

The File menu at the top of the screen lets you open and save car sets.
A car set includes the team and driver names, car colors, pit crew colors
and helmet colors.

When you open a car set file, you can choose either ArgEditor files (.arged) or
old F1ed files (.1ed).

When saving, you can save either an ArgEditor car set file, or a F1Ed file that
can be read by F1Ed. 

Game settings such as player horsepower, general grip level and weather settings
are _not_ saved in ArgEditor car set files, but _are_ saved in F1Ed files.


## Import and Export

You can import and export data from and to existing GP.EXE files.

For more details, see the [Importing and Exporting](importing-and-exporting.md) section.


## Undo and Redo

The Undo and Redo menu options simply apply the undo or redo function to the currently
active car/pit crew or helmet.

The same functionality is achieved by using Ctrl+Z for Undo, or Ctrl+Y for Redo.
