# Download

The latest version is %ArgEditorVersion%. It can be downloaded here: [argeditor.zip](http://www.manicomio.se/argeditor/download/ArgEditor-%ArgEditorVersion%.zip)


## Installation

It is better to be safe than sorry! Please make a backup of your F1GP folder before using
this software.

Unzip and place the argeditor.exe file in your F1GP/WC folder. Then run it from there.
